## 3. 内容を再確認するときの注意

- BV はパリティ・オラクル問題。文字列一致を返すパスワード判定ではない。
- 創薬例は2組のモデル係数 $g=0.8,1.6$。実在の薬候補 A/B/C の評価ではない。
- 第5節の $\hbar=1$ は単位の約束。電子エネルギーの計算だけで結合自由エネルギーや薬効を決めない。
- QPE は初期状態の固有成分と有限精度に依存する。下を常に一つの固有状態に固定しなければ動かないわけではない。
- Shor は $N=15,a=2$。$a=7$ の例ではない。測定結果から毎回周期4が得られるわけでもない。
- 最新動向の一次資料は第6節の各説明の直後に配置。ロードマップは予定として扱う。

## 4. 動画・実行方法

```bash
uv run python tools/quantum_videos/render_all.py --help
uv run python tools/quantum_videos/render_all.py --episodes ep3 --quality high
uv run python tools/quantum_videos/render_all.py --quality high
```

プロジェクトの Python は引数を解析してから、既存の Manim 専用仮想環境へ再実行する。`--help` に Manim は不要。既定の環境は以下。

- `QUANTUM_TTS_PYTHON`：`~/Code/Projects/anima/.venv/bin/python`
- `QUANTUM_MANIM_PROJECT`：`~/Code/Skills/learning/tools/manim-learning-video`
- `QUANTUM_MANIM_PYTHON`：上記プロジェクトの `.venv/bin/python`
- TTS モデル：`~/AIData/models/anima/speech/Irodori-TTS-v4.1-Small-MF-fp16`
- ASR：ローカル `http://127.0.0.1:8001/v1/audio/transcriptions`

別の Mac では専用ランタイム・モデルの準備が必要で、`uv sync` だけで映像生成までできるという意味ではない。シェルの PATH を書き換えず、既存の分離環境を使う。

実際の基底クラスは `VoicedTeachingScene`（外部の `TeachingScene` を継承）。`say_cue` と `finish_cue` で音声尺とアニメーションを合わせる。`VoicedQuantumScene` や `play_synced` という実装は存在しない。

出力は各話の MP4（1920×1080、30fps、48kHz音声）、JPG、VTT、`lesson.json`。チャプターは第1話5、第2話3、第3話5、第4話3の **計16**。音声キューはチャプターとは別で、15+11+14+12の **計52**。長さと開始秒は再生成される `lesson.json` を正とし、教材のボタンもその値を読む。

### ASR の意味

ASR は実音声を文字起こしして台本との正規化文字列類似度を計算する。`screened` は自動スクリーニングを通ったという意味で、発音や意味の完全一致を保証しない。低類似度は `review_required`、取得できなければ `unavailable` として記録する。数字・英字・同音語の認識誤りもあるため、空結果や例外を「検証済み」にしない。今回、式の読み上げを「一を足し、全体を二で割る」のように言い換え、認識結果も確認して再生成した。

## 5. 検証

数学の回帰テストは `tests/test_quantum_lesson_math.py` に収録。動画が描く確率を Qiskit の制御位相回路と照合し、符号・エネルギーの別解・2ビット QPE・標的0の BV・部分的重なりの局所コヒーレンスを確認する。

```bash
uv run pytest tests/test_quantum_lesson_math.py -q

```

各節の編集時には `tools/validate_docs.py` で構造・数式・Mermaid を確認する。実行付きレンダリングとブラウザ確認は、`just check` 内の `--no-execute` 検証とは別に必要。Pyodide はブラウザで時間・状態・ショット数を変更し、実際の更新を確認する。動画は数式の自動検証に加え、全チャプターの代表フレームを確認する。

今回の実施結果：

- `just check` 成功。テスト20件（今回追加した数学の回帰テスト19件を含む）が通過。既存の Preskill 第1・2章の OJS block count 警告は残るが、今回の教材の実行付きレンダリングは両ページとも成功。
- デスクトップ幅1440px・モバイル幅390pxで表示を確認。位相時計のスライダー、有限ショット実験の時間・状態・ショット数変更、位相の折り返しと非固有状態の表示を確認。Deutsch の並列比較式も列内に収まることを確認。
